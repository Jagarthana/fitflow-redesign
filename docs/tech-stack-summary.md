GitHub

## Reason for Selection

React Native was selected because it provides cross-platform development,
rapid development capabilities and support for complex mobile interfaces.

Node.js with Express provides the backend API and supports real-time
application requirements.

Firebase provides authentication, database and real-time services.

TensorFlow Lite supports on-device personalization, while ML Kit supports
computer-vision-based nutrition recognition.
