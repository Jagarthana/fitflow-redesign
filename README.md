# FitFlow Redesign

## Overview

FitFlow is a redesigned fitness tracking application developed
as part of the IT3060 Human Computer Interaction module.

The redesign focuses on improving user retention and engagement
through personalized workouts, social community features and
simplified nutrition tracking.

## Main Features

- AI-powered personalized workout plans
- Adaptive workout recommendations
- Social communities
- Fitness challenges
- Camera-based nutrition logging
- Progress dashboards
- Real-time notifications
- Secure authentication
